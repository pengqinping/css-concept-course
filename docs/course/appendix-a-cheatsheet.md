## 选择器

- `type` / `.class` / `#id` → 按标签、类、ID 命中元素 → 详见[第 02 篇](02-selectors.md)
- `*` → 通配选择器，通常只放重置规则里 → 详见[第 02 篇](02-selectors.md)
- 后代 / 子 / 相邻 / 兄弟组合器 → 用 DOM 关系收紧命中范围 → 详见[第 02 篇](02-selectors.md)
- `:first-child` / `:last-child` → 命中首尾兄弟 → 详见[第 02 篇](02-selectors.md)
- 属性选择器 → 按属性存在或取值匹配 → 详见[第 02 篇](02-selectors.md)
- `:is()` → 分组匹配，优先级取参数中最高项 → 详见[第 02 篇](02-selectors.md)
- `:where()` → 分组匹配且贡献零优先级 → 详见[第 02 篇](02-selectors.md)
- `:not()` → 从命中集合里排除参数 → 详见[第 02 篇](02-selectors.md)
- `:has()` → 由后代反向选中父级 → 详见[第 02 篇](02-selectors.md)
- `:nth-child()` / `:nth-of-type()` → 按兄弟序号筛选，后者只数同类型 → 详见[第 02 篇](02-selectors.md)
- `:hover` / `:active` → 命中指针悬停与按下状态 → 详见[第 30 篇](30-component-boundary.md)
- `:focus-visible` → 只在键盘等需要焦点环时命中 → 详见[第 24 篇](24-accessibility.md)
- `:checked` / `:disabled` → 命中表单控件的状态 → 详见[第 20 篇](20-forms.md)
- `:user-invalid` → 用户交互后才命中的校验失败态 → 详见[第 20 篇](20-forms.md)
- `::before` / `::after` → 插入装饰性伪元素 → 详见[第 02 篇](02-selectors.md)
- `::marker` / `::selection` → 改列表标记与选中文本 → 详见[第 02 篇](02-selectors.md)
- `::backdrop` → 给 dialog / popover 的背景层上样式 → 详见[第 22 篇](22-native-ui.md)
- `::part()` → 穿透 Shadow DOM 命中暴露部件 → 详见[第 30 篇](30-component-boundary.md)
- `:root` → 命中文档根元素，常用于挂令牌 → 详见[第 23 篇](23-architecture.md)
- `:scope` → 命中作用域根元素 → 详见[第 26 篇](26-scope-nesting.md)
