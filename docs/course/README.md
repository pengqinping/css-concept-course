# CSS 概念课：把样式从"试出来"变成"推出来"

这套课程面向**已经会写常见 CSS，但还在靠刷新浏览器猜结果**的人。目标不是再列一遍属性，而是把 12 个反复出问题的地方，各建立一个可以推演的心智模型。

课程与旧的 [CSS 学习手记](../README.md) 是两套东西：

- **本课程是主线**：按顺序学，每篇解决一个"为什么"。篇幅短、图和 demo 紧贴知识点。
- **旧手记是参考区**：按需查属性、查配方、查兼容性。它保留原结构，只修正错误，不再作为学习路径。

## 每篇的固定结构

1. **一个具体现象**：先描述你会遇到的怪事，不给术语。
2. **一句话模型 + 一张图**：先把直觉建立起来，再开始拆机制。
3. **机制拆解**：最多 4 步，每步回答"为什么"，不列属性字典。
4. **最小 demo**：一个概念、1–2 个可调参数、"先预测再揭晓"。
5. **容易误判的 2–3 件事**：只写真正会踩的坑。
6. **3 个动手任务**：每个都给可核对的预期结果，做完知道自己对了没有。

写作规范见 [STYLE.md](STYLE.md)。图示源文件在 `figures/`，最小 demo 在 [examples/minimal](../../examples/minimal/README.md)。

## 怎么学

- 每篇先只看图和"一句话模型"，合上页面自己预测 demo 的结果，再打开验证。
- demo 只用 1–2 个参数，故意做得小；复杂的多控件实验台留在旧示例库里做进阶。
- 遇到"这个属性还有哪些取值"再跳到参考区，不要在主线里扩张。
- 交互式版本：`course-site/index.html`，可直接双击打开，图与 demo 全部内嵌。
