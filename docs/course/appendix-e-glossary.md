# 附录 E · 术语表

本附录服务于 [课程总览](README.md)。

> 只收课程里出现过、且真正影响推理的词。每条是「术语 → 一句话人话解释 → 详见第 NN 篇」：这里帮你想起它管什么事，要问"为什么"回对应篇章。

## 一、渲染、层叠与值

- **CSSOM** → CSS 解析出的规则树，样式计算就是把它和 DOM 对上号 → 详见[第 01 篇](01-pipeline.md)

- **渲染流水线** → 样式计算 → 布局 → 绘制 → 合成，每道加工决定一类问题 → 详见[第 01 篇](01-pipeline.md)

- **Computed 值** → 结算完层叠和单位后的最终值，总是带具体单位 → 详见[第 01 篇](01-pipeline.md)

- **层叠 Cascade** → 多条声明抢同一个属性时的裁决过程 → 详见[第 03 篇](03-cascade.md)

- **来源 Origin** → 作者、用户、浏览器默认各站一个梯队 → 详见[第 03 篇](03-cascade.md)

- **层 Layer** → 用 `@layer` 写出来的显式优先级顺序 → 详见[第 03 篇](03-cascade.md)

- **优先级 Specificity** → 命中之后用来打平的那组计数 → 详见[第 03 篇](03-cascade.md)

- **作用域距离** → 多个 `@scope` 同时命中时，离根近的胜出 → 详见[第 03 篇](03-cascade.md)

- **继承 Inheritance** → 某些属性自动从父元素拿值，变量也走这条路 → 详见[第 04 篇](04-inheritance.md)

- **初始值** → 既没继承也没声明时，属性回到的起点 → 详见[第 04 篇](04-inheritance.md)

- **全局关键字** → `initial` / `inherit` / `unset` / `revert` 这类能写在任何属性上的值 → 详见[第 04 篇](04-inheritance.md)

- **自定义属性** → `--` 开头、由 `var()` 取用的 token 序列 → 详见[第 04 篇](04-inheritance.md)

- **设计令牌** → 用语义名承载颜色、间距等设计决策的变量 → 详见[第 23 篇](23-architecture.md)

- **包含块** → 百分比和定位先问"参照谁"的那个盒子 → 详见[第 06 篇](06-containing-block.md)

- **格式化上下文** → 一组子盒按什么规则摆放的环境 → 详见[第 07 篇](07-bfc.md)

- **BFC** → 块级格式化上下文，把内部布局和 margin 影响关在盒子里 → 详见[第 07 篇](07-bfc.md)

- **层叠上下文** → 一个独立的绘制家族，先比家族层级再比家族内部 → 详见[第 08 篇](08-stacking-context.md)

- **z-index** → 只在家族内部排序的号码，不是全局排名 → 详见[第 08 篇](08-stacking-context.md)

- **top layer** → 浏览器单独开的绘制层，在常规内容之上且不受祖先 `overflow` 裁剪 → 详见[第 22 篇](22-native-ui.md)

## 二、盒、尺寸与布局

- **盒模型** → content / padding / border / margin 四层叠成一个盒子 → 详见[第 05 篇](05-box-model.md)

- **内边距** → 内容与边框之间的缓冲，属于盒子自己 → 详见[第 05 篇](05-box-model.md)

- **外边距** → 盒子外面的透明间距，用来推开别人 → 详见[第 05 篇](05-box-model.md)

- **box-sizing** → 决定 `width` 描述内容层还是"内容 + 内边距 + 边框"那一层 → 详见[第 05 篇](05-box-model.md)

- **margin 折叠** → 正常流里垂直相邻的 margin 合并成一个，取较大者 → 详见[第 05 篇](05-box-model.md)

- **display** → 先决定元素生成什么类型的盒子 → 详见[第 12 篇](12-display-overflow.md)

- **visibility** → 藏起来但仍然占着布局空间 → 详见[第 12 篇](12-display-overflow.md)

- **overflow** → 内容超出边界时裁剪还是允许滚动 → 详见[第 12 篇](12-display-overflow.md)

- **固有尺寸** → 内容或资源自身带来的尺寸，不一定听容器的 → 详见[第 12 篇](12-display-overflow.md)

- **主轴** → Flex 里空间流动的方向，`justify-content` 管它 → 详见[第 15 篇](15-flex.md)

- **交叉轴** → 与主轴垂直的方向，`align-items` 管它 → 详见[第 15 篇](15-flex.md)

- **flex-basis** → 分配剩余空间之前，每项在主轴上的起点尺寸 → 详见[第 15 篇](15-flex.md)

- **剩余空间** → 容器尺寸扣掉 basis 与 gap 之后能分的那部分 → 详见[第 15 篇](15-flex.md)

- **min-size** → 项目拒绝收缩到内容最小尺寸以下的那道下限 → 详见[第 15 篇](15-flex.md)

- **轨道 Track** → Grid 的行或列，是空间而不是元素 → 详见[第 16 篇](16-grid.md)

- **网格线** → 轨道之间的分界，项目靠它定位 → 详见[第 16 篇](16-grid.md)

- **1fr** → 剩余空间的一份，下限默认是 `auto` → 详见[第 16 篇](16-grid.md)

- **minmax()** → 给轨道同时写下限和上限 → 详见[第 16 篇](16-grid.md)

- **隐式轨道** → 自动放置时额外生成的行或列 → 详见[第 16 篇](16-grid.md)

- **subgrid** → 子网格继承外层轨道，让多行对齐 → 详见[第 16 篇](16-grid.md)

- **查询容器** → 为 `@container` 提供尺寸条件的祖先 → 详见[第 17 篇](17-container-query.md)

- **容器查询** → 按组件自己的可用宽度改样式，不看视口 → 详见[第 17 篇](17-container-query.md)

- **容器单位** → `cqw` / `cqi` 这类以查询容器为基准的长度 → 详见[第 17 篇](17-container-query.md)

- **clamp()** → 带上下限的插值：先算首选值，再夹到边界 → 详见[第 18 篇](18-units.md)

- **rem** → 以根元素字号为参照的长度 → 详见[第 18 篇](18-units.md)

- **em** → 以当前元素字号为参照的长度 → 详见[第 18 篇](18-units.md)

- **vw** → 以视口宽度为参照的长度 → 详见[第 18 篇](18-units.md)

## 三、文字与视觉

- **行盒** → 文字排版时临时生成、决定行高的盒 → 详见[第 09 篇](09-typography.md)

- **基线** → 同一行文字与图片对齐时用的那条基准线 → 详见[第 09 篇](09-typography.md)

- **行高 line-height** → 行盒的高度来源，决定行与行之间的间距 → 详见[第 09 篇](09-typography.md)

- **行长** → 每行放多少字，和字号、行高一起决定阅读节奏 → 详见[第 09 篇](09-typography.md)

- **text-wrap: balance** → 让标题各行长度更均匀，减少末尾孤字 → 详见[第 09 篇](09-typography.md)

- **currentColor** → 指向当前 `color` 的关键字，改一处跟着变 → 详见[第 10 篇](10-color.md)

- **对比度** → 前景与背景的亮度差，决定文字读不读得清 → 详见[第 10 篇](10-color.md)

- **变换 Transform** → 布局完成后再改视觉坐标，不重新排版 → 详见[第 13 篇](13-transform.md)

## 四、动画、状态与可达性

- **插值** → 在两个值之间补出中间帧，动画才有"过程" → 详见[第 14 篇](14-animation.md)

- **过渡 Transition** → 状态改变时，在两个状态之间补间 → 详见[第 14 篇](14-animation.md)

- **关键帧** → 显式写出动画在某一时刻的样子 → 详见[第 14 篇](14-animation.md)

- **@starting-style** → 给初始帧一个样式，解决"动画结束才跳变" → 详见[第 14 篇](14-animation.md)

- **prefers-reduced-motion** → 用户要求减少动画时匹配的媒体偏好 → 详见[第 14 篇](14-animation.md)

- **伪类** → 按元素状态命中的选择器，如 `:hover` → 详见[第 30 篇](30-component-boundary.md)

- **伪元素** → 命中元素内部抽象部分的选择器，如 `::before` → 详见[第 30 篇](30-component-boundary.md)

- **能力查询** → 用 `(hover: hover)` 这类条件问设备能力，而不是问浏览器名字 → 详见[第 30 篇](30-component-boundary.md)

- **焦点可见性** → 键盘聚焦位置的可见提示，不能顺手用 `outline: none` 删掉 → 详见[第 24 篇](24-accessibility.md)

- **特性查询** → `@supports` 问"认不认这条语法"，只证语法、不证行为 → 详见[第 24 篇](24-accessibility.md)

- **渐进增强** → 基础状态先独立可用，再把能力作为叠加层加上去 → 详见[第 24 篇](24-accessibility.md)

## 五、响应式与工程

- **媒体查询** → 按视口尺寸或用户偏好切换规则 → 详见[第 19 篇](19-responsive.md)

- **断点** → 布局开始变坏的临界宽度，不是设备型号清单 → 详见[第 19 篇](19-responsive.md)

- **移动优先** → 先写窄屏基础样式，再逐步增强到宽屏 → 详见[第 19 篇](19-responsive.md)

- **meta viewport** → 让移动端使用有意义的布局视口 → 详见[第 19 篇](19-responsive.md)

- **@layer** → 把覆盖顺序写成可读的层声明 → 详见[第 23 篇](23-architecture.md)

- **嵌套** → 只改书写方式，编译后仍是扁平选择器 → 详见[第 26 篇](26-scope-nesting.md)

- **@scope** → 给样式一个 DOM 子树边界，并加上邻近性排序 → 详见[第 26 篇](26-scope-nesting.md)

- **:has()** → 把匹配方向反过来，由后代选中父级 → 详见[第 26 篇](26-scope-nesting.md)

## 六、性能与现代扩展

- **重排 Layout** → 重新计算盒子的尺寸与位置 → 详见[第 25 篇](25-rendering.md)

- **重绘 Paint** → 重新生成绘制指令和像素 → 详见[第 25 篇](25-rendering.md)

- **合成 Composite** → 按层叠顺序把各层叠成最终画面 → 详见[第 25 篇](25-rendering.md)

- **合成层** → 能被合成器独立处理的一层，数量和显存都有代价 → 详见[第 25 篇](25-rendering.md)

- **will-change** → 提前提示浏览器某属性要变，滥用反而更慢 → 详见[第 25 篇](25-rendering.md)

- **布局抖动** → 交替读写布局，把流水线硬拽回起点 → 详见[第 25 篇](25-rendering.md)

- **CLS** → 累计布局偏移，衡量非预期的视觉移动 → 详见[第 25 篇](25-rendering.md)

- **锚点定位** → 让浮层跟随命名元素，并保留基础定位作回退 → 详见[第 27 篇](27-modern-features.md)

- **视图过渡** → 捕获旧、新视图，再用伪元素树做切换动画 → 详见[第 27 篇](27-modern-features.md)

- **@page** → 描述纸张尺寸与页边距，但选不中任何 DOM 元素 → 详见[第 28 篇](28-print.md)

- **多列布局** → 把连续内容自动分栏，不是 Grid，也不等于打印分页 → 详见[第 29 篇](29-shapes-mix.md)

- **混合模式** → 按像素运算合成颜色 → 详见[第 29 篇](29-shapes-mix.md)

- **隔离 isolation** → 建立独立的层叠与混合边界，不等于 `contain` → 详见[第 29 篇](29-shapes-mix.md)

- **Shadow DOM** → 附着在元素上的独立文档树，隔离查询与多数作者样式 → 详见[第 30 篇](30-component-boundary.md)

- **::part()** → 按内部显式 `part` 名暴露的样式入口，不公开整棵影子树 → 详见[第 30 篇](30-component-boundary.md)
