盒模型与 margin

声明宽度不一定等于占位宽度。先分清 box-sizing，再处理百分比、负 margin 与块级布局里的 margin 折叠。

01 · box-sizing

同样的 width，不同的占位尺寸

content padding border margin 外侧

content-box（默认）

内容宽 14rem
高 10rem

占位：14 + 2.5 + 1 = 17.5rem
高度：10 + 2.5 + 1 = 13.5rem

.box {
  box-sizing: content-box;
  width: 14rem;
  height: 10rem;
  padding: 1.25rem;
  border: .5rem solid;
}

border-box

内容宽 10.5rem
高 6.5rem

占位：14rem × 10rem
padding 与 border 从声明尺寸中扣除

.box {
  box-sizing: border-box;
  width: 14rem;
  height: 10rem;
  padding: 1.25rem;
  border: .5rem solid;
}

margin 不参与 box-sizing 的计算；它始终在 border box 之外。实际 margin 是透明的，这里用米色底板帮助观察。

02 · 百分比

百分比 padding 按父容器宽度计算

即使子元素 width: 50%，padding: 10% 仍按父容器的内容宽度计算，而不是按自己的宽度计算。

50% 宽 + 10% padding
content-box：总宽度约为父容器的 70%，再加 8px 边框。 
.parent { width: 100%; }
.child {
  width: 50%;
  padding: 10%; /* 相对父容器内容宽度 */
  border: 4px solid;
  box-sizing: content-box;
}
03 · 负 margin

负 margin 让元素反向占用空间

开启后，第二、第三张卡片各自向左移动 2.5rem，产生有意的层叠效果。

第一张
margin-left: 0
第二张
margin-left: -2.5rem
第三张
margin-left: -2.5rem
当前：正常排列。

负 margin 不会改变 DOM 顺序或键盘焦点顺序，但可能造成文本重叠，应检查小屏与缩放场景。

04 · margin 折叠

用 flow-root 或 contain:layout 隔离折叠

子块上下各有 1rem margin。普通块布局中，首尾 margin 会与父元素折叠并“穿出”父框；建立独立格式化上下文后，margin 留在父框内。

选择父容器布局方式

父框（虚线）与子块

子块 · margin-block: 1rem
普通块：margin 穿出父框，父框高度为 3rem。

为什么会不同

display: flow-root 建立块级格式化上下文（BFC）；contain: layout 建立布局包含，也能阻止子元素 margin 与外界折叠。

父元素的 border 或 padding 本身能阻止首尾 margin 穿过父框；outline 不会，这里只用它做标记。flow-root 与布局包含也能隔离父子 margin；兄弟 margin 仍可在 BFC 内折叠。

/* 方案一 */
.parent { display: flow-root; }

/* 方案二 */
.parent { contain: layout; }
