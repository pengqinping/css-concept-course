03 · 函数伪类

:is / :where / :not / :has

普通卡片 徽标

:is() 匹配类列表，:where() 提供零优先级样式，:not() 排除弱化卡片，:has() 检测内部徽标。

另一张卡片

没有徽标，所以不会出现 :has(.badge) 的绿色外框。

可弱化卡片

加上 .is-muted 后，:not(.is-muted) 不再匹配标题。

:is(.tone-green, .tone-amber) .fn-title {
  color: #3f6b2a;
}

/* :where() 整组优先级为 0 */
:where(.tone-green, .tone-amber) {
  border-radius: 1rem;
}

.fn-card:not(.is-muted) .fn-title {
  text-decoration: underline;
}

/* 向前看子元素，不再只靠类名 */
.fn-card:has(.badge) {
  border: 2px solid #3f6b2a;
}

:is() 与 :not() 的优先级取参数中最具体的一项；:where() 始终为零。:has() 的优先级由 :has() 本身及其参数共同决定。

04 · 交互状态

:focus-visible 与 :user-invalid

键盘焦点

键盘导航时显示粗绿框；鼠标聚焦时只保留细灰框。:focus-visible 让浏览器按输入方式选择合适的焦点提示。

input:focus {
  outline: 2px solid #c9c4b8;
}
input:focus-visible {
  outline: 4px solid #3f6b2a;
}

用户造成的无效状态

输入错误格式，再按 Tab 离开，观察红色提示。

:user-invalid 只在用户交互后匹配无效控件；页面刚加载时，即使值为空，也不会立刻显示错误样式。

input:user-invalid {
  border-color: #a83f36;
  background: #fff0ed;
}
