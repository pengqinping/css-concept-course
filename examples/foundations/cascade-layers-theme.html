层叠层、关键字与主题

同一属性的胜出顺序不只是“选择器越具体越好”。先看来源与层叠层，再比较层内优先级；主题则交给 color-scheme 与 light-dark()。

01 · @layer

层顺序优先于选择器优先级

下面两个独立示例文档使用完全相同的选择器，只改变 @layer 声明顺序，胜出的颜色就会改变。层顺序在同一文档中一旦确立便不能反转，因此这里用隔离的示例上下文作对比。

components 在后，绿色胜出。

基础层 vs 组件层

@layer foundation, components;

/* 后面的 components 层优先 */
.layer-swatch { background: #3f6b2a; }

同一层内：优先级仍然有效

ID 选择器胜出

.specificity-swatch 与 #specificity-swatch 同层；ID 的优先级更高，即使它写在类规则之前。

.specificity-swatch { background: #e3a15f; }
#specificity-swatch  { background: #3f6b2a; }

非层叠的普通作者样式优先于所有层叠层；!important 的层叠层顺序则相反。本例只比较普通声明。

02 · revert-layer

退回较低层，而不是变成初始值

高层撤销，露出基础层

基础层的橙色
@layer base {
  .box { background: #b96f35; }
}
@layer upper {
  .box { background: revert-layer; }
}

非层叠样式仍然更强

非层叠的绿色

revert-layer 会忽略当前及更高层，但普通非层叠作者样式依旧优先于层叠样式。

/* 非层叠：优先级高于所有普通层 */
.revert-fallback { background: #3f6b2a; }
03 · 全局关键字

inherit / initial / unset / revert

父元素有一条 4px 绿色边框。观察子元素如何取得或丢弃它。

父元素：4px solid #3f6b2a
inherit
继承父边框
initial
边框初始值：无
unset
非继承属性 → initial
revert
回到用户/浏览器样式

inherit 强制继承；initial 使用属性初始值；unset 对继承属性等同 inherit、对非继承属性等同 initial；revert 回退到其他样式来源。

04 · light-dark()

用 color-scheme 切换明暗配色

选择 color-scheme

同一份 CSS，两种表面

light-dark(浅色值, 深色值) 根据当前元素的 color-scheme 选值，同时也会影响表单控件和滚动条。

主题令牌自动切换
当前：跟随系统。 
.theme-demo { color-scheme: light dark; }

.theme-demo {
  color: light-dark(#263020, #f4f1e9);
  background: light-dark(#fffdf7, #202a1d);
}

旧浏览器会忽略不支持的 light-dark() 声明，保留前面的普通颜色作为回退。
