自定义属性与类型化动画

自定义属性让值可以沿 DOM 继承、局部覆盖和集中换肤；注册 @property 后，浏览器还知道如何插值角度、百分比与颜色。

01 · 继承与局部覆盖

变量沿 DOM 传递，子元素也可以覆盖

父级预览：使用 --accent
子元素没有重新定义 --accent，因此继承父级的值；间距来自 --token-space。
当前：--accent: #3f6b2a（深绿）。 
.scope-card {
  --accent: #3f6b2a;
  --token-space: 1rem;
}

/* 只影响这个子树 */
.scope-card.is-overridden {
  --accent: #b96f35;
}

.scope-preview {
  background: var(--accent);
  padding: var(--token-space);
}

自定义属性默认继承。局部覆盖不会改变祖先或兄弟节点；未定义的变量通过 var() 求值时，其声明会变为无效。

02 · var() 回退

变量缺失时使用回退值

当前使用：回退橙色 #e8b36b
.preview {
  /* 变量不存在或无效时，使用逗号后的值 */
  background: var(--not-defined, #e8b36b);
}

.fallback-card.has-token {
  --not-defined: #3f6b2a;
}

回退值只在自定义属性缺失或保证无效时使用；不要把它当作任意 CSS 语法错误的通用修复。

04 · @property

注册类型后，自定义属性可以平滑插值

圆环角度、中心颜色和进度条宽度都通过注册过的自定义属性动画。

--dial-angle / --halo / --meter-value

syntax 定义可接受的类型，inherits: false 关闭继承，initial-value 提供缺失时的初始值。

@property --dial-angle {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}

@keyframes dial-spin {
  to { --dial-angle: 360deg; }
}

不支持 @property 的浏览器仍会显示图形，但自定义属性可能只在关键帧之间跳变，不能平滑插值。系统开启“减弱动态效果”时，本示例会停止动画并显示静态状态。
