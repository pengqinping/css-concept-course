能交给浏览器的，就不要重写。

Dialog 管理模态焦点，Popover 提供轻量浮层，Details 保留折叠语义。新浏览器增强动画，旧浏览器仍然可用。

Details 与 Summary

原生支持键盘展开与折叠；支持 ::details-content 时增加高度过渡。

什么是 ::details-content？
它表示 summary 之外的内部内容盒。配合 interpolate-size: allow-keywords，可以在 block-size: 0 与 auto 之间过渡，而不需要测量像素高度。
为什么仍然需要原生元素？
语义、焦点、屏幕阅读器状态与浏览器行为都由平台提供。自定义 div 要补齐这些能力，代码更多且更容易遗漏边界情况。

CSS 计数器

counter-reset 建立计数域，counter-increment 递增，counter() 生成内容。

  1. 确定计数范围在列表容器重置计数器。
  2. 按顺序递增每个列表项增加一次。
  3. 生成视觉标记用 ::before 输出，不改变列表语义。
.steps { counter-reset: field-step; }
.steps li { counter-increment: field-step; }
.steps li::before {
  content: counter(field-step);
}

固定布局与折叠边框

table-layout: fixed 按列宽分配空间，长内容不会撑乱布局；border-collapse: collapse 合并相邻单元格边框。窄屏时由外层容器横向滚动。

蕨类养护提示

明亮散射光、保持土壤微湿，避免空调直吹。原生 Popover 可使用 Esc 关闭。

轻量浮层
