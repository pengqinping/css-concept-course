Scroll-driven animations / Reduced motion

滚动不是触发器，而是时间轴。

本页用 scroll() 驱动整页进度，用 view() 驱动卡片进入视口时的揭示动画。向下滚动即可观察，不需要定时器。

向下滚动，让阅读进度开始流动

正在检测滚动驱动动画…

01

整页进度：scroll(root block)

滚动位置映射到 0%–100% 动画区间。JS 只更新无障碍数值与文本，不负责逐帧绘制进度条。

时间轴

animation-timeline: scroll(root block) 使用根滚动容器的块方向进度。

有效区间

animation-range: 0 100% 明确进度条从页面起点到终点完整显示。

回退

不支持时，脚本按 scrollY 与可滚动高度计算比例，设置 CSS 自定义属性。

.progress-fill {
  animation: page-progress linear both;
  animation-timeline: scroll(root block);
  animation-range: 0 100%;
}
@keyframes page-progress {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}
02

元素揭示：view()

view() 跟踪元素与滚动视口的关系。卡片从刚进入视口，到覆盖约三分之一视口时完成揭示。

entry 0%

动画从元素开始进入滚动视口时起步，而不是进入后才触发。

cover 35%

元素覆盖视口到 35% 时结束，滚动反向时动画也会自然反向。

可见性优先

没有 JS 时内容默认完全可见；只有确认支持后才由 CSS 接管揭示动画。

.reveal {
  animation: reveal-up linear both;
  animation-timeline: view();
  animation-range: entry 0% cover 35%;
}
@keyframes reveal-up {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0); }
}
03

双向、可逆、无滚动监听

原生时间线由浏览器合成，不需要在主线程持续读取布局。向上滚动时，所有动画都沿时间轴反向播放。

双向映射

动画进度与滚动位置同步，不存在触发一次后忘记重置的问题。

性能友好

transform 与 opacity 通常可以走合成路径，避免每帧触发布局计算。

能力检测

分别检测 scroll() 与 view()，只启用浏览器实际支持的增强。

提示：如果系统开启“减少动态效果”，本页会关闭滚动时间线和全部过渡，进度仍由静态数值准确表达，内容始终立即可读。
04

渐进增强清单

基础内容是真实 HTML，动画只是增强。即使脚本、IntersectionObserver 或 CSS 时间线全部不可用，也不会丢失任何段落。

@supports

新时间线规则只在对应属性受支持时解析。

IntersectionObserver

view() 不可用时，为卡片添加可见类，保留一次性揭示。

无动画模式

prefers-reduced-motion 优先于视觉风格，所有内容直接呈现。

@supports (animation-timeline: view()) {
  .reveal {
    animation: reveal-up linear both;
    animation-timeline: view();
    animation-range: entry 0% cover 35%;
  }
}

@media (prefers-reduced-motion: reduce) {
  .reveal { animation: none; opacity: 1; transform: none; }
}
