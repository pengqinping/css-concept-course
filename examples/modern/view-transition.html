为什么能追踪位置？

浏览器分别为新旧状态截图。相同 view-transition-name 的节点会从旧位置与尺寸动画到新位置，名称必须在同一时刻保持唯一。

if (document.startViewTransition) {
  document.startViewTransition(() => {
    applyState(); // 在回调内同步更新 DOM
  });
} else {
  applyState(); // 基础状态更新始终执行
}
