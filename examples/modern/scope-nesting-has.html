嵌套、:is() 与 :where()

下面三个块分别由旧语法与 @supports 增强。:where() 的优先级为零，便于外部覆盖；:is() 取参数列表中的最高优先级。

嵌套 hover 按钮

低优先级主题

:where(h3, p) 设置内边距，不会与组件选择器争夺优先级。

@supports selector(&) {
  .demo-button {
    &:hover { background: var(--green-dark); }
  }
}

@supports selector(:where(*)) {
  .where-demo :where(h3, p) { padding-inline: 4px; }
}
