CSS anchor positioning / Safe fallback

让浮层跟着目标，也留在屏幕里。

支持锚点定位时，CSS 使用 anchor() 与 @position-try 自动换边；否则脚本测量按钮与浮层，限制在视口安全区内。

交互演示

选择位置，然后打开浮层。把按钮移到右下角，可以观察自动回退到上方或左侧。

正在检测锚点定位…

核心声明

锚点名称由触发按钮声明，浮层用 position-anchor 引用；候选位置在溢出时依次尝试。

.anchor-trigger {
  anchor-name: --demo-anchor;
}

.anchor-panel {
  position-anchor: --demo-anchor;
  top: anchor(bottom);
  left: anchor(left);
  position-try-fallbacks: --above-left, --left-below;
}

@position-try --above-left {
  top: anchor(top);
  left: anchor(left);
  transform: translateY(-100%);
}

属性说明

anchor-name

为目标注册一个不参与渲染的隐式锚点，元素移动、滚动或改变尺寸时自动更新。

position-anchor

在浮层上引用目标名称，使后续 anchor() 能找到正确元素。

anchor(<edge>)

读取目标的 top、right、bottom、left 或 center 等边，可继续参与 calc()。

@position-try

定义候选布局。浏览器会检查空间，首个能完整容纳浮层的候选才会生效。

回退策略

JS 同时考虑视口左右、上下边界，并在滚动、缩放、目标移动后重新定位。基础交互不依赖新 CSS。
