    isolation 单独演示

    绿色是父级背景；黄色块的 z-index: -1。isolate 会创建新的层叠上下文。

    负层级子元素

    未 isolate：负层级元素可能落到父级背景之后。

    属性作用与代价

    • content-visibility: auto

      屏幕外内容可跳过渲染，但占位尺寸、滚动定位、查找与无障碍树更新都需要验证；不要用于需要保持状态的复杂组件。

    • contain: layout paint

      建立独立布局与绘制边界，子元素溢出父级 padding box 的部分会被裁剪；绝对定位或阴影可能被截断。

    • contain: size

      元素尺寸不再由内容推导。必须提供明确尺寸、最小高度或 contain-intrinsic-size，否则可能出现空白盒。

    • contain: content

      等价于 layout paint style，不包含 size；适合希望保持内容高度、又隔离绘制的工作单元。

    • isolation: isolate

      只创建层叠上下文，不裁剪、不改变尺寸，也不等于完整的 paint containment。

    .row {
  min-height: 132px;
  contain-intrinsic-size: auto 132px;
}

/* 屏幕外跳过；靠近视口时恢复真实尺寸 */
.row.visibility { content-visibility: auto; }

/* 隔离布局与绘制；溢出角标会被裁剪 */
.row.paint { contain: layout paint; }

/* 尺寸也隔离：高度由 CSS 决定，长文本不会撑高 */
.row.strict { contain: size layout paint; }

/* 只建立层叠上下文 */
.stack-root { isolation: isolate; }
