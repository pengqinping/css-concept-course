第一章 · 分页基础

先定义纸，再定义内容

打印样式不是屏幕样式的缩小版。屏幕可以无限延伸，纸张却有固定尺寸；屏幕上的卡片阴影、圆角和悬浮层，到了纸上可能变成无意义的墨迹。设计打印层时，应先确认纸张大小、方向、安全边距以及正文行长，再决定哪些组件需要保留、折叠或完全隐藏。

@page 接受 size 与 margin。本示例使用 A4 纵向，左右各 18 mm、上下分别为 20 mm 与 22 mm。较新的浏览器还支持页边距盒，可在纸张边缘放置页码和文档标题；支持程度不一致时，应保留正文自身的信息层级作为降级。

break-inside: avoid

这张卡片作为一个不可拆分单元。当剩余空间不足时，浏览器会把它移到下一页。它适合提示框、图注、签名区和小型数据块，不适合强制保护超过一页的长内容。

orphans 与 widows

orphans: 3 要求段首至少保留三行，widows: 3 要求段尾至少保留三行，避免一页以孤立的一行开始或结束。它们只影响行级分页，不能保证整段不跨页；若整段必须完整，再使用 break-inside: avoid。

分页规则需要真实的长内容来验证。短段落看起来完美，并不代表它在章节末尾、图片之后或表格之前仍然稳定。追加正文可以制造更多分页机会，再观察浏览器如何移动段落、卡片与表头。

不同的打印引擎对分页属性的支持并不完全相同。完成样式后，应至少在目标浏览器和“保存为 PDF”路径中各检查一次，重点寻找空白页、被截断的边框、重复表头缺失和背景色丢失。

最后，打印文档仍然需要语义。标题层级、表格表头、链接文字和阅读顺序不会因为进入打印样式而自动正确。把装饰性内容隐藏，把关键说明保留，是对纸张读者负责。

print-color-adjust: exact

深绿背景与暖白文字用于验证背景图形设置。浏览器若为了省墨而移除背景，正文仍应保持足够对比度，不能只依靠底色传达状态。

奇偶页页脚由 @page :left 与 @page :right 分别设置。

第二章 · 跨页表格

让表头在每一页重复

表格跨页后，thead { display: table-header-group; } 会在后续页面重复表头；每一行使用 break-inside: avoid，避免单元格内容被切断。页码、单位与列含义应留在表头或表脚中，而不是只出现在第一页。

本页核心规则

@page {
  size: A4 portrait;
  margin: 20mm 18mm 22mm;
  @bottom-right { content: counter(page); }
}
@page :first { margin-top: 28mm; }
@page :left  { @bottom-left { content: "左页 · 偶数页"; } }
@page :right { @bottom-left { content: "右页 · 奇数页"; } }

.chapter { break-before: page; }
.keep-card { break-inside: avoid; }
.body-copy { orphans: 3; widows: 3; }
thead { display: table-header-group; }
.ink-block { print-color-adjust: exact; }

@media print {
  .toolbar, .back-link, .screen-only { display: none !important; }
  .paper { width: auto; min-height: 0; padding: 0; box-shadow: none; }
}

兼容性提醒

@page 的页边距盒、:first、:left、:right 和页码计数器主要由 Chromium 系打印引擎较好支持；Safari 与 Firefox 的支持范围可能不同。分页属性本身较普遍，但跨页表头、表脚与强制分页仍应以实际打印预览为准。
