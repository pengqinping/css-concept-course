边界契约

:host
在影子树内为宿主元素设置布局、字体和默认变量。
:host([variant])
按外部属性切换变体，属性是组件公开 API 的一部分。
::slotted()
只匹配被分发进来的节点；深层后代需由页面样式自行管理。
::part()
外部只能修改显式标记 part="surface" 等少数样式入口。
自定义属性
--card-accent 与 --card-radius 自然继承进影子树，可局部覆盖。
组合事件
bubbles: true 与 composed: true 让事件穿过 Shadow DOM。
表单语义
宿主声明 formAssociated，用 setFormValue() 参与外层表单。
