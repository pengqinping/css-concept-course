Position & Stacking

定位与层叠上下文

用同一组按钮观察定位参照物与 inset，再滚动粘性区域、切换隔离，亲眼确认子元素的 z-index 能去哪里、不能去哪里。

1

定位方式与包含块

relative 保留原位置；absolute 相对最近的定位祖先；fixed 相对视口（除非祖先建立固定定位包含块）。

舞台：position: relative

试试：切到 absolute 后移除内层的 relative。方块会改为参照外层舞台。切到 fixed 后滚动页面，它仍贴着视口；用起点 / 终点 / 居中按钮改变 inset。

2

9999 也逃不出父级

父元素通过 isolation: isolate 建立独立层叠上下文。子元素的 z-index: 9999 只在这个上下文内部比较，无法越过外层 z-index: 2 的兄弟。

z-index: 9999

z-index: 2

点击按钮会同时移除父级的 isolation 和定位元素的 z-index（两者都会创建层叠上下文）。此时子元素回到舞台上下文，9999 才能盖住兄弟。其他上下文触发因素还有 opacity < 1、transform、filter、contain: paint 等。

3

sticky 的阈值在滚动容器里

绿色标题初始位于正常流中；容器滚动到它的起始位置后，top: 0 才让它吸附。它不会滚出父容器的边界。

到达阈值

滚动位置达到标题初始偏移量时，粘性约束开始生效。

持续吸附

继续滚动，标题停留在容器顶部；这是相对滚动祖先的固定，不是 fixed。

边界约束

滚动到底部时，标题会被父容器底边限制，最终随内容离开。

属性速查

position

static 忽略偏移；relative 视觉偏移且保留原位；absolute 脱离文档流；fixed 参照视口；sticky 跨越正常流与吸附状态。

inset / top 等

inset 是上、右、下、左的简写。三值写法可省略一侧为 auto；百分比相对包含块对应尺寸。

z-index

只对定位元素或 Grid / Flex 项目生效；数值只在同一层叠上下文内有可比性，不是“全局高度”。

isolation: isolate

强制建立新的层叠上下文，适合把组件内部的混合模式、阴影与高 z-index 限制在组件内。

sticky 条件

需要可滚动祖先、明确阈值（如 top）和足够空间；父元素 overflow: hidden 可能改变实际滚动容器。
