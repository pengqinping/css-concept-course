Scroll Snap

滚动吸附：横向与纵向

用触控板、鼠标滚轮、拖动滚动条或键盘方向键，观察卡片如何停在吸附点。按钮与参数控制会实时修改两个真实滚动容器。

第三张卡片设置了 scroll-snap-stop: always。用较大的滚轮手势滚动时，它会成为一次手势中无法越过的停靠点。

纵向滚动与 proximity

纵向容器默认使用 scroll-snap-type: y proximity：接近吸附点时自然停下，否则允许停在两屏之间，更适合长内容。

SECTION 01 / 04

用键盘也能滚动

容器获得焦点后，方向键可滚动，Page Down / Page Up 翻页，Home / End 到达首尾。示例也监听了这些按键，让每次操作精确导航到吸附点。

SECTION 02 / 04

对齐由子项声明

scroll-snap-align 写在每个卡片上，而不是只写在容器上。start 对齐起始边，center 则让卡片中心落在可视端口中心。

SECTION 03 / 04

滚动条也可以设计

scrollbar-width: thin 与 scrollbar-color 控制标准滚动条；旧式 WebKit 内核通过 ::-webkit-scrollbar 提供回退样式。

SECTION 04 / 04

尊重减少动态偏好

系统开启“减少动态效果”后，示例会把平滑滚动降为即时滚动。你仍可用下方开关手动选择 scroll-behavior。

3

两个容器共享的参数

调整内边距、滚动链和滚动条样式，然后回到上方实际滚动。所有设置都通过 CSS 自定义属性和标准属性即时生效。

32px

在任一容器边界继续滚动，对比 contain 与 auto：前者把滚动留在容器内，后者可能把剩余滚动交给页面。none 还会禁用橡皮筋等边缘效果。iOS Safari 对滚动条样式与 overscroll 的支持有限，应以实际设备为准。

.scroller {
  overflow-x: auto;           /* 或 overflow-y: auto */
  scroll-snap-type: x mandatory; /* 或 y proximity */
  scroll-padding-inline: 2rem;
  scroll-behavior: smooth;
  overscroll-behavior: contain;
  scrollbar-width: thin;
  scrollbar-color: #3f6b2a #ded9cc;
}
.card {
  scroll-snap-align: start;
  scroll-snap-stop: normal;   /* 特殊卡片可设 always */
}

滚动吸附速查

snap-type

轴由 x / y 指定；mandatory 强制吸附，proximity 接近才吸附。none 会关闭吸附。

snap-align

写在被吸附元素上，可用 start / center / end；两值时第一个是块轴，第二个是行轴。

snap-stop

always 阻止用户一次手势越过该元素；normal 允许掠过。不是“禁止访问”的语义属性。

scroll-padding

定义滚动端口的吸附留白，类似容器级 padding，但只影响滚动与吸附位置，不移动普通布局内容。

overscroll-behavior

contain 隔离滚动链；none 同时禁用边缘效果；auto 保留浏览器默认行为。

可访问性

保留可见焦点、足够大的点击目标、键盘导航与即时滚动回退；不要让吸附动画导致内容难以停下。
