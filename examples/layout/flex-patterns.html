空间分配的三步口诀

1. basis 定基准

flex-basis 优先于 width / height 设置主轴初始尺寸；auto 才回退到尺寸属性或内容尺寸。

2. 有剩余就 grow

总剩余空间乘以“自身 grow / 所有 grow 之和”。flex-grow: 0 的项目不参与增长。

3. 有缺口就 shrink

负剩余空间按“自身 shrink × basis / 所有乘积之和”分配收缩，避免小 basis 项目被过度压缩。

min-width: 0 是逃生口

Flex 项目默认 min-width: auto，长单词、图片等会撑住项目。设为 0 后才能小于内容最小尺寸。

order 只改视觉顺序

order 越大越靠后；键盘 Tab 与屏幕阅读器仍按 DOM 顺序，因此不要用它表达关键语义顺序。

gap 不等于 margin

gap 只产生项目之间的间距，不污染首尾边缘；容器换行时同时作用于行与列。
