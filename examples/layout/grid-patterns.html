CSS Grid Patterns

Grid：从命名区域到自适应

先看网格线和命名区域如何共同描述页面骨架，再调整轨道最小宽度、切换密集排列，最后用 subgrid 对齐嵌套内容。

1

命名网格线与命名区域

grid-template-columns / rows 定义轨道；方括号给线命名，grid-template-areas 则把矩形区域命名为 header、sidebar 等，便于整体重排。

[side-start] → [side-end][main-start] → [main-end]
headergrid-area: header · 跨两列
sidebar左侧 11rem 轨道
mainminmax(0, 1fr) 吸收剩余空间
footergrid-area: footer

当前用 grid-area 按命名区域放置四个项目。

命名线适合精确放置：grid-column: main-start / main-end。命名区域适合骨架：窄屏只需改写区域字符串为 "header" "main" "sidebar" "footer"，四个项目本身不必移动。点击按钮可在两种等价放置方式之间切换。

查看命名网格完整代码 
.layout {
  display: grid;
  grid-template-columns:
    [side-start] 11rem [side-end main-start]
    minmax(0, 1fr) [main-end];
  grid-template-rows:
    [header-start] auto [header-end content-start]
    minmax(11rem, 1fr) [content-end footer-start]
    auto [footer-end];
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  gap: .75rem;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
2

auto-fit + minmax 自适应卡片

repeat(auto-fit, minmax(min(100%, 12rem), 1fr)) 会根据容器宽度自动决定列数；有剩余空间时各列平分，过窄时单列也不会溢出。

项目数量

auto-fit 会折叠空轨道，让现有项目拉伸填满；若想保留空轨道，把 auto-fit 换成 auto-fill。min(100%, 12rem) 避免最小轨道在极窄容器中溢出。

3

跨轨道与 auto-flow: dense

大卡片占两列两行，随后的小卡片会遇到它留下的空洞。开启 dense 后，浏览器会回填较早的空洞，而不是继续向后寻找空位。

4

subgrid：让子网格继承父轨道

每张卡片的内部网格跨越父网格全部列。支持时，grid-template-columns: subgrid 让三列严格对齐父网格，并自动继承父级的 gap。

示例使用 @supports (grid-template-columns: subgrid)：不支持时回退为相同的显式三列，布局仍可用。行方向也可使用 grid-template-rows: subgrid，但需要父网格先定义相应行轨道。

Grid 速查

fr 与 minmax

1fr 分享剩余空间；minmax(0, 1fr) 把最小尺寸设为 0，避免长内容撑破轨道。

隐式网格

项目多于显式轨道时会生成隐式轨道，尺寸由 grid-auto-columns / rows 决定。

span

grid-column: span 2 跨越两列；grid-row: span 2 跨越两行，不必知道具体线号。

auto-flow

row 按行放置；column 按列放置；追加 dense 会尝试回填空洞。

subgrid

子项跨父网格轨道后，可让自身的一个轴继承父网格轨道，实现跨卡片对齐。
