CSS 概念课 / 02 层叠

三个开关，看谁说了算

层叠不是"后写的覆盖先写的"，而是依次闯关：来源与重要性 → 层 → 优先级 → 书写顺序。每开一个开关，看它在第几关起作用。

调一调

A / B 争夺这个颜色
A = color: red（先写，未分层） B = color: blue（后写）
1 来源与重要性→ 2 层→ 3 优先级→ 4 书写顺序

先预测

只开「后写规则」时按钮是什么颜色？保持它开着，再打开「@layer」呢？最后打开「!important」呢？把三个颜色写下来再揭晓。

揭晓 / 验证

(1) 只开后写规则：蓝色。前面几关全打平，后写的 B 靠书写顺序胜出。
(2) 再开 @layer：变回红色。A 未分层，B 在 @layer late；普通声明里未分层强于分层，层在顺序之前比较，所以 B 写得再晚也赢不了。
(3) 再开 !important：蓝色。B 的 !important 属于来源与重要性，先于层判定，盖过 A 的普通声明。
