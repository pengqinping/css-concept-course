CSS 技术教程 / 11 背景与边框

背景画到哪条边，由 clip 说了算

边框始终画在背景之上。半透明边框会透出底下的背景，所以改动 background-clip 时，变化首先出现在那圈边框区域。

调一个参数

10px 半透明黑边框 + 渐变背景
画到边框外沿 止于内边距外沿 只覆盖内容

先预测

把 background-clip 从 border-box 改成 padding-box，那圈 10px 半透明边框会变成什么？再改成 content-box，padding 区又会发生什么？先写答案再揭晓。

揭晓 / 验证

border-box 时背景一直画到边框外沿，边框区是渐变与 25% 黑的叠加。改成 padding-box 后背景止于内边距外沿，边框区只剩 25% 黑叠在舞台底色上，与内部背景之间出现清晰接缝。再改成 content-box，padding 区也不画背景，于是从边框内沿到内容之间又多出一条舞台底色的带。背景没变、边框没变，变的只是绘制区域。
