08 · 谁盖住谁

家族 A 里有 z-index:9999，家族 B 里只有 z-index:0。先看谁赢，再用滑块改变 A 的家族层级去核对。

先预测

默认状态下，A 的 z-index 是 1，B 是 2。A 家里的 9999 能盖住 B 家里的 0 吗？

揭晓 / 验证

不能。浏览器先比家族：A(1) 低于 B(2)，B 家整体压在 A 家之上，所以 B 家里的 0 盖住 A 家里的 9999。把滑块拖过 2（A 变成 3 或 4），结果翻转；而子块的 9999 和 0 全程没变，说明这一轮比较发生在家族层，不在子块层。
