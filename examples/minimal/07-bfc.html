CSS 技术教程 / 07 BFC

一道边界，把 margin 关在里面

BFC 不是一串触发条件，而是一道边界。它把盒内的竖直 margin 折叠关在里面，不让穿出去改写外面的布局。米色块是父元素背景，顶部虚线是参照位置。

调一调

子元素，margin-top: 50px

父元素没有 border、没有 padding；子元素的 margin-top 固定 50px。开关之外没有任何数值变化。

先预测

打开 flow-root 后，父元素高度如何变化？子元素相对父顶部的位置又怎么变？先写下答案再揭晓。

揭晓 / 验证

父元素高度增加 50px（从只包住子元素高度，变成 50px + 子元素高度）；子元素相对父顶部的偏移从 0 变成 50px。父元素自身的 computed margin-top 始终是 0px，变的是那 50px 空隙画在父元素外面还是里面。

没开时，父子 Margin 折叠且结果放在父元素外面，父元素整体被推下去，父子之间没有空隙。开了 flow-root，边界挡住折叠，50px 变成父元素内部的一段空白，父元素不再被推下去。border 和 padding 也能阻断，但机理是插进实体让两者不再相邻，不是立边界。
