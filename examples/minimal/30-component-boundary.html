30 · 状态何时成立，样式到哪里为止

组件边界是一道有闸门的墙：普通选择器过不去，::part() 与 CSS 变量按约定通道穿过。这里只看谁能改影子树里的按钮。

先预测

页面写 demo-card button { color: red }，影子树里的按钮会变红吗？给内部按钮加 part="action" 后，::part(action) 能命中它吗？

揭晓 / 验证

不会变红：普通后代选择器被 Shadow DOM 边界挡住，页面 querySelectorAll 命中 0 个内部按钮。::part(action) 只命中显式标了 part 的节点，能把它改绿并加琥珀边框。CSS 变量沿继承链进入影子树，但只有内部写了 var(--accent) 才生效；跨树普通声明由外层胜出，!important 则反转。Part 名是对外接口，改名会让外部规则直接失效。

调一个参数

页面里那条 demo-card button 规则始终存在，它选不中影子树内部。
