CSS 技术教程 / 02 选择器

从右往左，把选择器读成筛选关卡

右端锚定"是谁"，往左每一段只对同一个候选元素再问一句。组合器没有选中任何元素，它只回答"这个候选的父/兄是谁"。

调一个参数

  • 纯文本项
  • 内含 span 的项
  • 带类名的项
右端锚点 li→ 伪类逐项再筛→ 左侧确认祖先

先预测

选到 ".list li:has(span)" 时，哪一项会被高亮？这条链里右端锚点是谁，左边两段各在问什么？先写下来再揭晓。

揭晓 / 验证

只有第二项（内含 span 的 li）高亮。右端锚点是最右侧的 li，它先圈出 3 个候选；":has(span)" 对同一个候选再问一句"你内部有 span 吗"，把集合缩到 1 个；左侧 ".list" 最后确认这个候选的祖先带 list 类。读选择器的顺序与写它的顺序是反的。若换成 ".list li:nth-child(2n)"，"再筛"这一步按所有兄弟从 1 计数，命中的是第二项。
