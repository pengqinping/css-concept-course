CSS 技术教程 / 06 包含块

50% 的尺子搭在哪

width: 50% 里的 50% 是一个待解析的比例。定位方式一变，参照盒就换：普通流参照 content box，绝对定位参照 padding box。

调一调

width: 50%

父元素：content 宽 400px、padding 20px、border 2px。虚线框标出本次用来解析百分比的参照盒；窄屏可横向滚动。

先预测

把子元素从 static 切到 absolute 后，width: 50% 的实际像素增加多少？先写下数字再揭晓。

揭晓 / 验证

增加 20px：200px 变 220px。static 参照父元素 content box：400 × 50% = 200px；absolute 参照 padding box：(400 + 20×2) × 50% = 440 × 50% = 220px。父元素的 border 2px 始终在参照盒之外，不参与计算。换 position 同时换掉了两件事：量百分比的尺子，和摆放子元素的原点。
