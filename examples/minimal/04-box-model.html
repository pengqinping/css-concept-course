width 描述的是哪一层

box-sizing 不改变任何尺寸，只改变 width 描述哪一层：content-box 把 300px 标在内容层，border-box 把 300px 标在边框外沿。下面的色条就是四层剖面，会跟着参数实时变形。

调一调

20px 5px

box-sizing: content-box

content 层

box-sizing: border-box

content 层

先预测

width 固定 300px。把 padding 从 20px 调到 10px、border 从 5px 调到 0：两种模式的"内容宽"和"占位宽"各是多少？先写下四个数字再揭晓。

揭晓 / 验证

content-box：内容 300px，占位 300 + 2×10 + 0 = 320px——width 标在内容层，padding 向外加价，border 归零就只剩 padding 的加价。border-box：内容 300 − 2×10 − 0 = 280px，占位 300px——width 锁住整盒，省下的 padding 和 border 从内容层里扣。拖动滑块，用下方实测读数核对。
