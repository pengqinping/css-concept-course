28 · 屏幕上的长页，怎么落到有限的纸上

@media print 管元素画什么，@page 管纸张多大。这里只看一件事：页眉等元素在打印时是否退出布局。

先预测

页面有一行页眉、一条深色导航、一个工具栏。调用 window.print() 后，页眉在打印时还会显示吗？外部链接地址会不会出现？

揭晓 / 验证

不显示。@media print 在输出目标是打印或打印预览时参与层叠，.page-header { display: none } 让页眉退出布局，导航与工具栏同理，链接后用 ::after 追加地址。@page 描述纸张尺寸与页边距，不是选择器，选不中任何元素；页边距盒里的页码由 counter(page) 填。打开模拟开关核对 display 读数。
