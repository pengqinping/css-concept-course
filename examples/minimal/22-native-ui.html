22 · 原生弹层

dialog.showModal() 与 popover 都进 top layer：绘制在所有常规内容之上，不受祖先 overflow 裁剪。只演示一件事：层级不是数值。

先预测

右上角那个 z-index: 9999 的橙色徽标，在模态 dialog 打开后能盖住它吗？打开 popover 呢？按 Escape 谁会关闭？

揭晓 / 验证

都不能。top layer 是浏览器单独的一层，z-index 只在自己的层叠上下文里比大小，9999 到不了那里；徽标还在常规层，会被 dialog 的遮罩盖在下面。模态 dialog 让背景 inert、圈定焦点、Escape 可关；popover 默认非模态，支持 light dismiss（点外部或 Escape 关闭）。判断模态看 :modal，不看有没有遮罩。

调一个参数

打开后 Tab 试背景是否可聚焦，再按 Escape。徽标的 z-index 始终是 9999。

观察台

三种原生能力各解一种问题：details/summary 是零 JS 的折叠；dialog.showModal() 是模态；popover 是轻量浮层。它们的状态由浏览器维护，CSS 只读不写。
