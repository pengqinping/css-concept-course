CSS 技术教程 / 05 盒模型

width 描述的是哪一层

box-sizing 不改变任何尺寸，只改变 width 描述哪一层：content-box 描述内容层，border-box 描述"内容 + 内边距 + 边框"那一层。width 固定为 300px。

调一调

20px 5px

box-sizing: content-box

content 层

box-sizing: border-box

content 层

先预测

width 固定 300px、border 不变，把 padding 从 0 调到 10px：两种模式的占位宽度各增加多少？先写下两组数字再揭晓。

揭晓 / 验证

content-box 增加 20px（左右各 10px）；按默认 border=5px 算，占位从 310px 变成 330px，公式 300 + 2×padding + 2×border。border-box 增加 0px，占位始终锁在 300px；变的是内容宽，按默认 border=5px 从 290px 变成 270px，公式 300 - 2×padding - 2×border。
