CSS 技术教程 / 14 状态的变化

插值出来的值，在层叠里也有席位

transition 靠事件给出前后两帧，animation 靠 @keyframes 写出时间轴。从低到高：普通作者声明 → CSS 动画 → 作者 !important → CSS 过渡。

调两个参数

transition：背景色

600ms 线性插值，观察中途的灰。

animation：文字颜色

深灰与琥珀之间循环，观察席位。

动画盒席位 过渡盒席位

先预测

给两个变化都加上 !important：动画盒和过渡盒分别会怎样？哪一个是 !important 压不住的？先写答案再揭晓。

揭晓 / 验证

动画盒被压住：作者 !important 高于动画值，文字恒定深灰 #23291e。过渡盒压不住：过渡值高于所有重要声明，那 600ms 里你看到的仍是逐帧插值的灰，结束后才稳定在 !important 给出的深色。结论是 transition 不会被 !important 覆盖，animation 会。两者都是"插值产生的值参与层叠"，只是席位一高一低。
