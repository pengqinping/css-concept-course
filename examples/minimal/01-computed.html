一条声明，三张快照

同一个 width，在 Styles 是字面量，在 Computed 是结算后的像素，在 Layout 是盒子的实际几何。切换那条冲突声明，看三道关各自看到什么。

调一调

.demo-box

盒子没有 padding / border，所以 Computed 与 Layout 读到的数字相同，但它们是不同阶段的产物。

先预测

把开关从关拨到开（宽度 200px 变 240px），盒子的占位宽度增加多少？请写出数字再揭晓。

揭晓 / 验证

增加 40px（200 变 240）。getComputedStyle 从 200px 变成 240px；getBoundingClientRect().width 从 200 变成 240。Styles 里两条声明并存，胜出的那条进入计算；Computed 是样式计算的输出；Layout 是布局结算后的几何。三者是同一条声明在流水线不同位置的快照。
