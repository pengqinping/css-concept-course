12 · 为什么动画会卡

属性改动从流水线的不同站点进入。落得越靠前，后面重做的越多。

先预测

让方块从 120px 走到视觉上的 300px。改 width 与改 transform，哪种不会让旁边的兄弟标记位移？

揭晓 / 验证

改 transform 不会。transform 只改视觉层的位置，布局盒宽度与流中占位不变（offsetWidth 仍是 120px），兄弟标记原地不动；改 width 会让布局盒变宽，兄弟标记被推开 180px。前提：transform 只走合成需要元素独立成层，本例已用 will-change 提示。用 Performance 录制 Main 轨道：改 width 出现 Layout 与 Paint 段，改 transform 主要剩 Composite Layers。

点击任一模式按钮即施加对应改动，再点"复位"回到起点。
