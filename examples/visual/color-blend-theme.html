色彩混合与明暗主题

从感知均匀的 OKLCH 出发，用 color-mix() 生成中间色，再用 currentColor、light-dark() 与混合模式构建一致的主题系统。

multiply + isolate

色彩控件

OKLCH：按感知亮度组织色阶

OKLCH 的 L 表示感知亮度，C 表示彩度，H 表示色相角。相同 L 的不同颜色通常具有相近的视觉明度，比直接修改十六进制更容易得到均匀色阶。

L 92%
C .045
L 80%
C .10
L 65%
C .16
L 50%
C .16
L 35%
C .10
:root {
  --accent: oklch(65% 0.16 120);
}

color-mix()：按比例混合

在两个颜色之间插值。改变比例时，浏览器直接计算新颜色，可用于 hover、边框和强调色，不需要 JavaScript 计算色值。

50% 深绿 + 50% 琥珀
background: color-mix(
  in srgb,
  #3f6b2a 50%,
  #d49a3a
);

currentColor：跟随文字颜色

图标、边框和背景引用 currentColor 后，会自动继承元素当前 color。换主题或状态色时，只需改一个属性。

currentColor 图标与边框同色
背景也使用 currentColor

light-dark() 与 color-scheme

light-dark(浅色, 深色) 根据元素使用的 color-scheme 自动选色；color-scheme 同时影响表单控件、滚动条等浏览器 UI 的明暗外观。

主题感知卡片

同一段 CSS 会在浅色与深色配色之间切换。深色模式不只是把白色换成黑色，还应重新检查正文、边框和强调色的对比度。

强调色 · light-dark(#3f6b2a, #9fbf7c)
.card {
  color-scheme: light;
  background: light-dark(#fffdf7, #24301f);
  color: light-dark(#25301f, #eef2e7);
}

mix-blend-mode：元素与背景混合

混合模式会让当前元素与背后的颜色相互作用。multiply 适合叠色，screen 适合柔光，difference 会产生强烈反色效果。

COLOR

isolate 开启：圆只与同一隔离组内的内容混合。

.disc {
  mix-blend-mode: multiply;
}
.stage {
  isolation: isolate;
}

isolation: isolate：控制混合边界

隔离会创建新的层叠上下文。组内元素仍可互相混合，但不会穿透出去影响祖先背景；关闭隔离时，混合可能延伸到卡片之外。

Aa isolate
Aa normal

把左侧隔离卡片与右侧普通卡片并排观察：两者内部都有绿色圆和文字，但只有左侧把混合结果限制在自己的组内。实际项目通常对组件根节点启用 isolate，避免 hover 特效污染页面背景。
