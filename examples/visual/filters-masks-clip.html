Mask / 视觉基础 04

裁剪、遮罩与投影

clip-path 决定元素的几何轮廓，mask 决定像素透明度，drop-shadow 则沿真实轮廓生成投影；它们用途相近，但结果并不相同。

裁剪与遮罩控件

clip-path：inset / circle / polygon / path

裁剪路径之外的区域不可见，也不会响应指针事件。基础形状适合规则图形，path() 可描述复杂的贝塞尔曲线。

inset()
clip-path: inset(12% round 28px);

mask-image：用透明度控制显隐

遮罩图的黑色代表透明，白色代表显示（默认 luminance 模式）；本示例使用 alpha 通道，不透明处显示，透明处隐藏。棋盘格用于暴露透明区域。

MASK
mask-image: linear-gradient(90deg, transparent, #000);
mask-size: 100% 100%;
mask-position: center;
mask-repeat: no-repeat;
mask-composite: add;

mask-size 控制遮罩图尺寸，mask-position 控制位置。多张遮罩可以用 mask-composite 合并；不同浏览器的旧版 WebKit 属性值命名与标准属性不同。

filter: drop-shadow()

投影算法会读取元素渲染后的 alpha 轮廓。对于半透明遮罩、SVG 或不规则形状，它能生成贴合内容的阴影。

drop-shadow：沿形状轮廓

box-shadow：跟随盒模型

.leaf {
  filter: drop-shadow(14px 18px 18px rgb(36 54 24 / .32));
}

box-shadow：投影盒模型

box-shadow 围绕元素的 CSS 盒绘制，性能和可控性通常更好，适合卡片、按钮和输入框。它不会读取遮罩或 SVG 内部的透明细节。

如何选择？
规则矩形卡片优先 box-shadow；带透明背景的插画、圆角图标和文字水印需要轮廓投影时，再使用 drop-shadow()。两者也可以叠加，形成层次更丰富的阴影。
.card {
  box-shadow: 14px 18px 18px rgb(36 54 24 / .32);
}

本页同时应用两种投影并保持参数一致，便于直接比较投影范围。拖动顶部滑块可以观察轮廓与盒模型之间的差异。
