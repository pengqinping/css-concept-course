Surface / 视觉基础 03

背景、边框与滤镜

用多层渐变构建背景，以 border-image 绘制装饰边框，再组合阴影、filter 与 backdrop-filter，制造有层次的材质感。

背景与滤镜控件

多层渐变、尺寸与混合

background-image 可以叠加多个渐变，第一层位于最上方；background-size 分别控制每层尺寸，background-blend-mode 控制层与层之间的混合。

层叠出来的风景5 层渐变 · 尺寸与混合模式实时可调
background-image:
  radial-gradient(...),
  repeating-linear-gradient(...),
  linear-gradient(...);
background-size: 180px 180px, 180px 180px, 100% 100%;
background-blend-mode: normal, multiply, soft-light;

背景层顺序与 background-blend-mode 列表一一对应。平铺纹理适合无限延伸；大尺寸渐变更适合作为氛围底色，避免高频纹理干扰正文阅读。

border-image：把渐变画在边框上

九宫格切片把来源图分成四角、四边和中心。渐变也可以作为来源，适合节日卡片、票据和装饰性边框。

一张植物学观察卡

边框来自 linear-gradient，而不是额外的图片文件。边缘可拉伸、重复或取整平铺。

border-image-source: linear-gradient(...);
border-image-slice: 1;
border-image-width: 12px;
border-image-repeat: stretch;

注意：border-image 不受 border-radius 圆角裁剪，装饰边框通常需要保持直角。

box-shadow：偏移、模糊与扩散

四个长度依次表示水平偏移、垂直偏移、模糊半径和扩散半径；颜色支持透明通道。多个阴影用逗号分隔。

阴影卡片
box-shadow
box-shadow: 14px 18px 26px 0px rgb(43 65 29 / .28);

filter：对元素整体做滤镜

多个滤镜函数按顺序应用。blur、brightness、contrast、saturate 与 hue-rotate 可组合成复古、柔和或高对比风格。

filter: blur(0px) brightness(100%) contrast(100%) saturate(100%) hue-rotate(0deg);

backdrop-filter：模糊元素背后的内容

普通 filter 处理元素自身，backdrop-filter 则采样并处理元素背后的画面，常用于毛玻璃、吸顶导航和图片遮罩。

FROST
磨砂玻璃卡片

背后纹理被模糊，文字与边框仍保持清晰。调整模糊半径观察采样区域。

background: rgb(255 253 247 / .25);
backdrop-filter: blur(10px) saturate(135%);
