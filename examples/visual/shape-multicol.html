Flow / 视觉基础 05

多栏与文字环绕

用多栏排布长文，用 float 与 shape-outside 让段落沿圆形、多边形等轮廓流动，建立杂志式的阅读节奏。

多栏与环绕控件

多栏：count / width / span / rule

column-count 指定栏数，column-width 指定理想栏宽；两者同时设置时浏览器会兼顾可用宽度。栏线、栏间距和跨栏标题可进一步建立层级。

山野观察笔记

清晨的林间有光穿过叶片，露水沿着叶脉缓缓滑落。多栏排版让这类观察文字拥有更舒展的横向节奏。

光与影的层次

当一束阳光落在不同高度的枝叶上，亮度会形成明显的梯度。靠近树冠的区域明亮而温暖，靠近地面的阴影则更冷、更柔和。记录这些变化，比单纯描述颜色更能传达空间感。

排版也是类似的过程：标题、正文、引文和栏线共同组织信息的层次。合适的栏宽让视线不必移动太远，稳定的栏间距则帮助读者在一行结束后迅速找到下一行。

阅读不是一次看完，而是在行与行之间不断确认方向。

垂直节奏

段落之间保留一致的间距，可以让长文保持呼吸。避免标题孤零零地留在栏底，也避免一句话被拆到两栏。跨栏标题像一条横向道路，把上下文重新连接起来。

当内容较少时，平衡栏高会让各栏长度接近；当容器高度固定时，自动填充模式会按顺序填满一栏再进入下一栏。实际页面需要根据阅读目标和响应式布局选择策略。

响应式取舍

窄屏上多栏通常不适合正文阅读。把 column-width 设置为合适的最小宽度，浏览器能根据容器自动减少栏数；标题则可以通过 column-span: all 保持完整，避免被挤压成窄小碎片。

column-count: 3;
column-width: auto;
column-gap: 32px;
column-rule: 1px solid #c8d3bc;
column-fill: balance;

h2 { column-span: all; }

float + shape-outside：沿形状环绕

shape-outside 必须作用于浮动元素，它不会改变元素自身的视觉形状；视觉轮廓由 clip-path 或 border-radius 控制。shape-margin 在环绕轮廓外再留出呼吸空间。

图形轮廓

文字环绕是版式中最直观的空间关系。当图形是圆形时，段落会沿着圆弧逐行收窄；当图形是多边形时，文字边缘会出现折线；如果关闭 shape-outside，文字则只围绕矩形外框排列。

这种效果常用于杂志插图、人物肖像和植物图鉴。图形不需要是图片，纯色块、渐变甚至透明元素都可以参与环绕。重要的是先让元素浮动，再定义它的外部形状，否则 shape-outside 不会产生文字回流。

shape-margin 相当于环绕区域的“安全距离”。数值越大，文字离视觉图形越远。对于深色背景上的浅色文字，或者轮廓复杂的插画，适当增加间距可以减少压迫感，让阅读更轻松。

注意 shape-outside 只影响同一格式化上下文中的行框，不会自动处理其他浮动元素、网格或绝对定位内容。复杂版面可以借助容器和清晰的结构来控制文字流向。

.shape {
  float: left;
  width: 190px;
  aspect-ratio: 1;
  border-radius: 50%;
  shape-outside: circle(50% at 50% 50%);
  shape-margin: 24px;
}
