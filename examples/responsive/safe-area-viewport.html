vh、svh、lvh、dvh 的实际高度

四根色条都声明为视口高度的 22%。工具栏变化时，dvh 跟随变化，svh 保持最小高度，lvh 保持最大高度。

实际渲染高度：—色条设了 4rem 最小高度，极矮视口下差异会被下限掩盖。

为什么移动端 100vh 会“多一截”？

模拟器把最大视口固定为整块屏幕。绿色浏览器工具栏出现后，100vh 与 100dvh 会延伸到工具栏下面。

稳定方案：页面主舞台使用 min-height: 100svh，内部文档自然滚动；只有确实需要“贴住当前可视区域”的沉浸组件才使用 100dvh。

内容始终从安全位置开始min-height: 50svh 演示
.page-stage {
  min-height: 100vh;  /* 回退 */
  min-height: 100svh; /* 稳定主舞台 */
}

env(safe-area-inset-*)：避开刘海与手势区

安全区域变量只在支持且需要避让的设备上返回非零值。模拟开关可让桌面端也直观看到效果。

viewport-fit=cover
关键操作区

按钮与正文留在安全 inset 内

四边分别读取：safe-area-inset-top、right、bottom、left。不要直接写死数值，因为不同设备与横竖屏的 inset 不同。

max() 同时保留设计所需的基础留白，并与真实安全区域取较大值。

.safe-screen {
  padding-top: max(1rem, env(safe-area-inset-top, 0px));
  padding-right: max(1rem, env(safe-area-inset-right, 0px));
  padding-bottom: max(1rem, env(safe-area-inset-bottom, 0px));
  padding-left: max(1rem, env(safe-area-inset-left, 0px));
}
  • 想要延伸到屏幕边缘时，在 meta 中加 viewport-fit=cover。
  • 不支持 env() 的旧浏览器忽略相关声明，基础 1rem 留白仍然可用。
  • 不要用固定定位把关闭按钮压在 home 指示条上。
