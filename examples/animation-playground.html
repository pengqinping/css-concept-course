动效实验台

比较 transform 过渡和 Grid 行高折叠。系统开启“减弱动态效果”时，动画会自动降级。

transform
这段内容高度未知，但 grid-template-rows: 0fr → 1fr 仍然可以平滑展开。收起时内容不会参与可见布局。
.box {
  transition: transform 500ms cubic-bezier(.2, .8, .2, 1);
}
.box.moved {
  transform: translateX(5rem) rotate(18deg) scale(1.12);
}

.collapse {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 350ms ease;
}
.collapse.open { grid-template-rows: 1fr; }
.collapse > div { overflow: hidden; }
