Motion CSS / 02

时间，也是一种设计材料

同一个位移，缓动函数会改变节奏；滚动时间线让进度直接来自页面位置。所有演示均可用键盘操作，并在“减少动态效果”下自动降级。

transition timing：比较四种节奏

点击卡片让圆点移动，再次点击返回。位移距离和持续时间完全相同，只有 transition-timing-function 不同。

.runner {
  transition: transform 900ms cubic-bezier(.2, .8, .2, 1);
}
.card[aria-pressed="true"] .runner {
  transform: translateX(9rem);
}

@keyframes 与 animation-composition

上行只运行位移关键帧；下行同时运行位移与呼吸关键帧，并通过 composition: add 叠加 transform 矩阵。

检测中

replace（默认）：后一个动画覆盖同属性。这里只演示基础位移。

位移

add：把缩放叠加到位移上，圆点在移动中呼吸；不支持时回退为单纯位移。

叠加
@keyframes travel { to { transform: translateX(12rem); } }
@keyframes breathe { to { transform: scale(1.3); } }

.composite-dot {
  animation: travel 2.4s ease-in-out infinite alternate,
             breathe 900ms ease-in-out infinite alternate;
  animation-composition: add;
}

view() 与 scroll() 滚动时间线

两个容器都可以用鼠标滚轮或键盘滚动。支持时，进度条由滚动位置直接驱动，不需要监听 scroll 事件。

view(block)检测中

元素进入、穿过、离开视口时推进动画；适合卡片揭示和阅读进度。

View timeline

滚动观察色条随卡片进入与离开而变化。

不支持时显示静态完整色条，不遮挡内容。

scroll(nearest block)检测中

以最近滚动容器为时间来源；适合阅读进度、章节指示与长页面导航。

向下滚动：顶部色条会从 0% 增长到 100%。

时间线由浏览器在合成阶段驱动，通常比 JavaScript 逐帧更新更平滑。

进度只是视觉反馈；真正的阅读位置仍由正常文档流决定。

继续滚动，观察进度到达终点。

键盘用户可以先聚焦容器，再使用方向键或 Page Down。

回退状态为静态色条；不支持时功能不依赖动画。
@supports (animation-timeline: view()) {
  .view-fill {
    animation: timeline-grow linear both;
    animation-timeline: view(block);
    animation-range: entry 0% exit 100%;
  }
}
@supports (animation-timeline: scroll()) {
  .scroll-fill {
    animation: timeline-grow linear both;
    animation-timeline: scroll(nearest block);
  }
}

@starting-style：元素“出现之前”的样式

原生 dialog 自带焦点管理、Esc 关闭与模态语义。支持时，打开与关闭都有入场 / 退场过渡。

检测中

正在检测起始样式支持…

@starting-style {
  dialog[open] {
    opacity: 0;
    transform: translateY(1rem) scale(.97);
  }
}
dialog {
  transition: opacity 280ms ease,
              transform 280ms ease,
              display 280ms allow-discrete,
              overlay 280ms allow-discrete;
}
可访问性检查：开启系统“减少动态效果”后，循环动画停止、滚动时间线变为静态进度、过渡即时完成。焦点样式不会被移除，信息也不依赖动画才能理解。

从起始样式进入

对话框打开前先应用 @starting-style 中的透明、下移状态，再过渡到最终位置。按 Esc 或下方按钮关闭。
