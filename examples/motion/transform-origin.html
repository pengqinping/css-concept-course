Motion CSS / 01

同一个变换，不同的原点

transform-origin 决定缩放、旋转和倾斜围绕哪个点发生。悬停、Tab 聚焦或点击下方卡片，比较三种原点的运动轨迹。

2D / 3D 组合变换

三张卡片使用完全相同的 translate3d()、rotateX/Y/Z()、scale() 与 skewX()，只有变换原点不同。浅色圆点标记原点位置。

左上角transform-origin: 0 0

像被图钉固定在角落，倾斜幅度更明显。

中心transform-origin: center

最平衡的默认值，适合卡片悬浮。

右下角transform-origin: 100% 100%

围绕底部支点旋转，常用于抽屉与铰链。

.origin-scene { perspective: 800px; }

.origin-button {
  transform-origin: 0 0; /* 每张卡片设置不同原点 */
  transition: transform 420ms cubic-bezier(.2, .85, .25, 1);
}
.origin-button:hover,
.origin-button:focus-visible,
.origin-button[aria-pressed="true"] {
  transform: translate3d(.35rem, -.45rem, 0)
             rotateX(12deg) rotateY(-14deg) rotateZ(8deg)
             scale(1.08) skewX(-5deg);
}

perspective 与 preserve-3d

3D 回退视图

当前浏览器不支持 preserve-3d，仍可通过按钮与文字理解各面关系。

perspective 给 3D 变换增加“近大远小”的透视感；数值越小，透视越强。

transform-style: preserve-3d 让子元素保留在同一个 3D 空间中。若省略它，立方体的六个面会被压平到父元素平面。

  • 六个面都用 translateZ() 或旋转后推出 4.5rem。
  • backface-visibility: hidden 隐藏背向镜头的面。
  • 按钮支持 Enter / Space；减少动态效果时保留最终状态、取消过渡。
.cube-button { perspective: 900px; }
.cube {
  transform-style: preserve-3d;
  transform: rotateX(-22deg) rotateY(28deg);
}
.cube-face.front { transform: translateZ(4.5rem); }
.cube-face.right { transform: rotateY(90deg) translateZ(4.5rem); }

性能提示：优先动画化 transform 与 opacity，避免在每一帧触发布局。3D 面很多时，再考虑 will-change，不要无节制使用。
